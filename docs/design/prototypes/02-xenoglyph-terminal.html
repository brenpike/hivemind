02 // Intercepted entity dossiers

Six entities detected

Four bioforms and two composites, reconstructed from intercepted traffic: designation, function, and the boundary each one will not cross.

  • Dossier 0x01

    Entity 0x01 · Bioform

    Overlord

    Function
    Orchestrator
    Invoke
    hivemind:overlord, session default

    Routes each request to a workflow, runs the workflow state machine and its run ledger, and owns branches, checkpoint commits, version bumps, PRs and review routing. Delegates all implementation; it never writes code.

03 // Workflow: standard-delivery

State-machine transcript

Every run is a state machine with a ledger. The cursor walks the real states; the decoded procedure explains each one.

run :: standard-delivery

  1. 00plandirective
  2. 01git_preflightpreflight
  3. 02branchnever trunk
  4. 03implement_stepwaves 1..n
  5. 04checkpointmolt / wave
  6. 05version_bump_decisionbump-type
  7. 06validategate
  8. 07local_reviewcodex
  9. 08open_prship
  10. 09github_review_loopwatch

ledger: .hivemind/runs/<run-id>/state.json

  1. 01 Route

    hivemind:route-workflow picks standard-delivery, analysis-only, pr-feedback-remediation, hatchery-dispatch or exploratory-intent-session. A trivial one-file change takes the Reflex fast path, which skips the router, the ledger and the cerebrate.

  2. 02 Record

    The ledger lives at .hivemind/runs/<run-id>/state.json, and each state result is normally validated against the workflow definition before the run advances.

  3. 03 Plan

    The cerebrate returns the directive.

  4. 04 Branch

    Git preflight, then a compliant working branch: feature/, bugfix/, hotfix/, refactor/, chore/, docs/, test/, ci/. The swarm never commits to trunk.

  5. 05 Build in waves

    hivemind:next-wave selects every ready step whose dependencies are met and whose files do not overlap. Drones and changelings build those steps in parallel, with one checkpoint commit (a molt) per wave.

  6. 06 Gate

    A version-bump decision (hivemind:bump-type), then validation.

  7. 07 Review

    The local-reviewer runs its adversarial review loop. Needs the codex companion.

  8. 08 Ship and watch

    The overlord opens the PR and watches it by default. It fixes, pushes, replies to and resolves actionable feedback from Codex, Copilot or Claude reviewer bots until reviewer approval, merge, close, or an idle hour. Opt out by saying so in the request or by setting HIVEMIND_SKIP_PR_WATCH. Agents never merge. You do.

Brood protocol

The cerebrate splits big work into independent strains. After you approve, each strain runs as its own overlord in its own git worktree (.claude/worktrees/<brood-id>/<short>) and its own detached tmux session, with its own branch and PR.

The hatchery watches via hivemind:brood-status.

hatchery ── awaits your approval
 │
 ├──┬ strain a  own overlord
 │  ├─ worktree <brood-id>/<short>
 │  ├─ tmux     detached session
 │  └─ branch ── PR
 ├──┬ strain b  own overlord
 │  └─ branch ── PR
 └── watch: hivemind:brood-status

04 // Anomaly signals

Signals in the noise

The swarm names what it detects. Some signals stop the run; some only advise.

Flare Halt · asks you
An agent can't safely resolve something. The overlord stops and asks you.
Reflex Fast path
The trivial fast path. One-file changes skip the router, the ledger and the cerebrate.
Mutation Decay Mandatory stop
Fixes undo each other: break-fix-break. A mandatory stop.
Creep Stagnation Advisory
Diminishing returns. An advisory early exit.
Root-Cluster One fix
Several findings share one root. Plan one structural fix.
Merge-Advised Humans merge
A bounded tail remains. The swarm recommends merge; humans merge.

Decided and journaled

Routine judgment calls are decided and journaled.

Returned to you

Irreversible, architectural or safety-relevant calls, and every merge, always come back to you.

05 // Install

Establish uplink

Three commands. Each one selects whole on click or tap, so you can copy it with your usual shortcut.

uplink :: claude code

  1. In Claude Code

    >/plugin marketplace add https://github.com/brenpike/hivemind.git

  2. Then

    >/plugin install hivemind@brenpike

  3. Then, in each project

    >/hivemind:seed-hive
  4. >

Requirements

  • bash (macOS, Linux or WSL)
  • git
  • gh
  • jq
  • the Claude Code CLI
  • tmux (only for brood mode)

Optional companions

  • claude-mem (memory)
  • codex (local pre-PR review)
  • caveman (compressed output)
