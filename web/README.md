# hivemind website

The repo-root `README.md` is the canonical source of truth for all website content. This site (`web/`) mirrors that content. There is no automated sync. Any content edit must trace back to a claim in `README.md`.

## Prototypes

`web/prototypes/` holds standalone, single-file design explorations. They are not loaded by `scripts/main.js` and are not covered by `web/tests/`, but they are deployed with the site. Their copy still traces back to `README.md`, like every other page.
