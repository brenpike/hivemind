Hivemind

Claude Code plugin

Multi-agent orchestration framework for Claude Code. Coordinates specialized bioforms to plan, build, review, and ship code, so you don't have to manage the pipeline yourself.

You are the Overmind. The swarm acts on your intent.

Install the swarm View on GitHub

Move or touch to scatter the swarm. Press and hold to call it to you. Tap a heading to re-encode it.

The six forms

One mind, six specialised forms

Four bioforms and two reviewer composites. The overlord is the hub; every other form is a spoke it dispatches. Hover or tap a form to light its cluster.

  • Overlord

    Orchestrator

    Bioform · hivemind:overlord · session default

    Routes each request to a workflow, runs the workflow state machine and its run ledger, and owns branches, checkpoint commits, version bumps, PRs and review routing. It delegates all implementation and never writes code.

  • Cerebrate

    Strategist · read-only

    Bioform

    Researches the codebase and returns the directive: STEP-NNN steps with exact file scopes, dependencies, risks and a delivery shape (single, multi or brood). Never writes files.

  • Drone

    Builder

    Bioform

    Implements code, fixes bugs, refactors, and updates tests and release metadata within an explicitly assigned file scope. The default owner of every step.

  • Changeling

    Shaper

    Bioform

    Presentational UI/UX: markup, styling, layout, design tokens, visual states and presentational accessibility, within an assigned file scope.

  • Local-Reviewer

    Pre-PR

    Reviewer composite

    Runs an adversarial Codex review loop before the PR exists, up to 10 iterations. Fixes simple findings (2 files or fewer), escalates complex ones, and stops on break-fix cycles. Needs the codex companion.

  • GitHub-Reviewer

    Post-PR · one-shot

    Reviewer composite · stateless

    Fetches and classifies review feedback, fixes, pushes, replies and resolves threads. Dispatched by the hivemind:github-review-loop skill.

standard-delivery

How a run works

Eight beats from your intent to a reviewed pull request. Each state result is normally validated against the workflow definition before the run advances.

  1. Route

    hivemind:route-workflow picks standard-delivery, analysis-only, pr-feedback-remediation, hatchery-dispatch or exploratory-intent-session.

    A trivial one-file change takes the Reflex fast path, which skips the router, the ledger and the cerebrate.

  2. Record

    The ledger lives at .hivemind/runs/<run-id>/state.json, and each state result is normally validated against the workflow definition before the run advances.

  3. Plan

    The cerebrate returns the directive.

  4. Branch

    Git preflight, then a compliant working branch: feature/, bugfix/, hotfix/, refactor/, chore/, docs/, test/, ci/.

    The swarm never commits to trunk.

  5. Build in waves

    hivemind:next-wave selects every ready step whose dependencies are met and whose files do not overlap. Drones and changelings build those steps in parallel, with one checkpoint commit (molt) per wave.

  6. Gate

    Version-bump decision (hivemind:bump-type), then validation.

  7. Review

    The local-reviewer runs its adversarial review loop. Needs the codex companion.

  8. Ship and watch

    The overlord opens the PR and watches it by default. It fixes, pushes, replies to and resolves actionable feedback from Codex, Copilot or Claude reviewer bots until reviewer approval, merge, close, or an idle hour.

    Opt out by saying so in the request or by setting HIVEMIND_SKIP_PR_WATCH. Agents never merge. You do.

Parallel strains

Brood

The cerebrate splits big work into independent strains. After you approve, each strain runs as its own overlord in its own git worktree (.claude/worktrees/<brood-id>/<short>) and its own detached tmux session, with its own branch and PR. The hatchery watches via hivemind:brood-status.

Who decides

Autonomy

Routine judgment calls are decided and journaled. Irreversible, architectural or safety-relevant calls, and every merge, always come back to you.

What the swarm tells you

Signals

Flare
An agent can't safely resolve something; the overlord stops and asks you.
Reflex
The trivial fast path.
Mutation Decay
Fixes undo each other, break-fix-break. A mandatory stop.
Creep Stagnation
Diminishing returns. An advisory early exit.
Root-Cluster
Several findings share one root; plan one structural fix.
Merge-Advised
A bounded tail remains; the swarm recommends merge, humans merge.

Install

Three commands in Claude Code. Select a command to copy it.

01 Add the marketplace

/plugin marketplace add https://github.com/brenpike/hivemind.git

02 Install the plugin

/plugin install hivemind@brenpike

03 Seed each project

/hivemind:seed-hive

Run the first two once in Claude Code, then seed the hive in each project.

Requires

  • bash (macOS, Linux or WSL)
  • git, gh and jq
  • The Claude Code CLI
  • tmux: only for brood mode
  • node: only for the optional local Codex review

Optional companions

  • claude-mem: memory
  • codex: local pre-PR review
  • caveman: compressed output
