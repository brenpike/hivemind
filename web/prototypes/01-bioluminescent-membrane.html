Hivemind

Multi-agent orchestration framework for Claude Code. Coordinates specialized bioforms to plan, build, review, and ship code — so you don't have to manage the pipeline yourself.

You are the Overmind. The swarm acts on your intent.

Install the hive View the source

The organisms

Six minds, one cytoplasm

Four bioforms do the work. Two composites review it. Each stays inside the membrane it is given.

  • Orchestrator · bioform

    Overlord

    hivemind:overlord · session default

    Routes each request to a workflow, runs the workflow state machine and its run ledger, and owns branches, checkpoint commits, version bumps, PRs and review routing. Delegates all implementation and never writes code.

  • Strategist · bioform

    Cerebrate

    read-only

    Researches the codebase and returns the directive: STEP-NNN steps with exact file scopes, dependencies, risks and a delivery shape — single, multi or brood. Never writes files.

  • Builder · bioform

    Drone

    default owner of every step

    Implements code, fixes bugs, refactors, and updates tests and release metadata within an explicitly assigned file scope.

  • Shaper · bioform

    Changeling

    presentational UI/UX

    Shapes markup, styling, layout, design tokens, visual states and presentational accessibility — within an assigned file scope.

  • Pre-PR · composite

    Local-Reviewer

    needs the codex companion

    Runs an adversarial Codex review loop before the PR exists, up to 10 iterations. Fixes simple findings (2 files or fewer), escalates complex ones, and stops on break-fix cycles.

  • Post-PR · composite

    GitHub-Reviewer

    stateless · one-shot

    Fetches and classifies review feedback, fixes, pushes, replies and resolves threads. Dispatched by the hivemind:github-review-loop skill.

Standard-delivery

How a run works

One intent travels down a single tendril. Every beat is recorded, validated, and handed to the organism that owns it.

  1. 01Route

    hivemind:route-workflow picks standard-delivery, analysis-only, pr-feedback-remediation, hatchery-dispatch or exploratory-intent-session.

    A trivial one-file change takes the Reflex fast path, which skips the router, the ledger and the cerebrate.

  2. 02Record

    The ledger lives at .hivemind/runs/<run-id>/state.json, and every state result is validated against the workflow definition before the run advances.

  3. 03Plan

    The cerebrate returns the directive.

  4. 04Branch

    Git preflight, then a compliant working branch: feature/, bugfix/, hotfix/, refactor/, chore/, docs/, test/, ci/. The swarm never commits to trunk.

  5. 05Build in waves

    hivemind:next-wave selects every ready step whose dependencies are met and whose files do not overlap. Drones and changelings build those steps in parallel, with one checkpoint commit — a molt — per wave.

  6. 06Gate

    The version-bump decision (hivemind:bump-type), then validation.

  7. 07Review

    With codex installed, the local-reviewer runs its adversarial review loop.

  8. 08Ship and watch

    The overlord opens the PR and watches it by default. It fixes, pushes, replies to and resolves actionable feedback from Codex, Copilot or Claude reviewer bots until reviewer approval, merge, close, or an idle hour.

    Opt out by saying so in the request or by setting HIVEMIND_SKIP_PR_WATCH. Agents never merge — you do.

Budding

The brood

The cerebrate splits big work into independent strains. After you approve, each strain runs as its own overlord in its own git worktree (.claude/worktrees/<brood-id>/<short>) and its own detached tmux session, with its own branch and PR.

The hatchery watches via hivemind:brood-status.

Chemical signals

What the swarm tells you

  • Flare

    An agent can't safely resolve something; the overlord stops and asks you.

  • Reflex

    The trivial fast path.

  • Mutation Decay

    Fixes undo each other — break-fix-break. A mandatory stop.

  • Creep Stagnation

    Diminishing returns. An advisory early exit.

  • Root-Cluster

    Several findings share one root; plan one structural fix.

  • Merge-Advised

    A bounded tail remains; the swarm recommends merge. Humans merge.

Germination

Install

Plant the spore once in Claude Code, then seed every project you want the hive to live in.

In Claude Code

/plugin marketplace add https://github.com/brenpike/hivemind.git
/plugin install hivemind@brenpike

Then, in each project

/hivemind:seed-hive

Requirements

Requires bash (macOS, Linux or WSL), git, gh, jq and the Claude Code CLI; tmux only for brood mode.

Optional companions

  • claude-mem — memory
  • codex — local pre-PR review
  • caveman — compressed output
