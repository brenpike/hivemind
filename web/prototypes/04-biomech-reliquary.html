Orchestration for Claude Code

Hivemind

Multi-agent orchestration framework for Claude Code. Coordinates specialized bioforms to plan, build, review, and ship code, so you don't have to manage the pipeline yourself.

You are the Overmind; the swarm acts on your intent.

I · The reliquary

Six chambers

Six agents. The first four are bioforms; the two reviewers are composites.

  • Bioform · Orchestrator

    Overlord

    hivemind:overlord Session default

    Routes each request to a workflow, runs the workflow state machine and its run ledger, and owns branches, checkpoint commits, version bumps, PRs and review routing. It delegates all implementation and never writes code.

  • Bioform · Strategist

    Cerebrate

    Read-only

    Researches the codebase and returns the directive: STEP-NNN steps with exact file scopes, dependencies, risks and a delivery shape (single, multi or brood). It never writes files.

  • Bioform · Builder

    Drone

    Default step owner

    Implements code, fixes bugs, refactors, and updates tests and release metadata within an explicitly assigned file scope. The default owner of every step.

  • Bioform · Shaper

    Changeling

    Presentational

    Presentational UI/UX: markup, styling, layout, design tokens, visual states and presentational accessibility, within an assigned file scope.

  • Composite · Pre-PR

    Local-Reviewer

    Needs codex

    An adversarial Codex review loop before the PR exists (up to 10 iterations). It fixes simple findings (2 files or fewer), escalates complex ones, and stops on break-fix cycles. Needs the codex companion.

  • Composite · Post-PR

    GitHub-Reviewer

    Stateless One-shot

    Fetches and classifies review feedback, fixes, pushes, replies and resolves threads. Dispatched by the hivemind:github-review-loop skill.

II · The spine

How a run works

One standard-delivery run, vertebra by vertebra.

  1. 01

    Route

    hivemind:route-workflow picks standard-delivery, analysis-only, pr-feedback-remediation, hatchery-dispatch or exploratory-intent-session. A trivial one-file change takes the Reflex fast path, which skips the router, the ledger and the cerebrate.

  2. 02

    Record

    The ledger lives at .hivemind/runs/<run-id>/state.json, and every state result is validated against the workflow definition before the run advances.

  3. 03

    Plan

    The cerebrate returns the directive.

  4. 04

    Branch

    Git preflight, then a compliant working branch (feature/, bugfix/, hotfix/, refactor/, chore/, docs/, test/, ci/). The swarm never commits to trunk.

  5. 05

    Build in waves

    hivemind:next-wave selects every ready step whose dependencies are met and whose files do not overlap. Drones and changelings build those steps in parallel, with one checkpoint commit (molt) per wave.

  6. 06

    Gate

    A version-bump decision (hivemind:bump-type), then validation.

  7. 07

    Review

    With codex installed, the local-reviewer runs its adversarial review loop.

  8. 08

    Ship and watch

    The overlord opens the PR and watches it by default. It fixes, pushes, replies to and resolves actionable feedback from Codex, Copilot or Claude reviewer bots until reviewer approval, merge, close, or an idle hour. Opt out by saying so in the request or by setting HIVEMIND_SKIP_PR_WATCH. Agents never merge. You do.

Strains

The brood

The cerebrate splits big work into independent strains. After you approve, each strain runs as its own overlord in its own git worktree (.claude/worktrees/<brood-id>/<short>) and its own detached tmux session, with its own branch and PR. The hatchery watches via hivemind:brood-status.

Nerve signals

Signals

Flare

An agent can't safely resolve something; the overlord stops and asks you.
Reflex
Fast path
The trivial fast path.

Mandatory stop
Fixes undo each other, break-fix-break; a mandatory stop.

Advisory
Diminishing returns; an advisory early exit.
Root-Cluster
One structural fix
Several findings share one root; plan one structural fix.
Merge-Advised
Humans merge
A bounded tail remains; the swarm recommends merge, and humans merge.

Autonomy

What comes back to you

Routine judgment calls are decided and journaled. Irreversible, architectural or safety-relevant calls, and every merge, always come back to you.

III · The inscription

Install

  1. In Claude Code, add the marketplace
    /plugin marketplace add https://github.com/brenpike/hivemind.git
  2. Then install the plugin
    /plugin install hivemind@brenpike
  3. Then, in each project
    /hivemind:seed-hive
Requires
bash (macOS, Linux or WSL), git, gh, jq and the Claude Code CLI; tmux only for brood mode.
Optional companions
claude-mem (memory), codex (local pre-PR review), caveman (compressed output).
